# 単語クイズ

自分で問題を入力して覚える、ブラウザだけで動く暗記アプリです。
クイズ（ノーマル／自己採点／タイムアタック）、単語帳、赤シート、テキスト変換ツールがあります。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目（デザイン） |
| `script.js` | 動作（問題の解析・クイズ・保存など） |

3つのファイルは同じフォルダに置いてください。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（Public）
2. 「Add file」→「Upload files」で上の3ファイルをアップロードして「Commit changes」
3. 「Settings」→「Pages」を開き、Source を「Deploy from a branch」、Branch を `main` と `/(root)` にして「Save」
4. 1〜2分後、`https://ユーザー名.github.io/リポジトリ名/` で開けるようになります

更新するときは、ファイルをアップロードし直すだけで反映されます（表示が変わらないときはブラウザを再読み込み）。

## 問題の書き方

| 種類 | 書き方 | 例 |
|---|---|---|
| 記述 | `問題-答え・解説` | `日本の首都は？-東京・政治の中心` |
| 別解 | 答えを `\|` で区切る | `日本の首都は？-東京\|とうきょう` |
| 選択 | `問題-①A②B③C④D=正解` | `正しいのは？-①東京②大阪③名古屋=①・解説` |
| 穴埋め | 行頭に `+`、隠す部分を `( )` | `+日本の首都は(東京)である` |
| 長文 | `++`：空欄ごとに1問（他の空欄は表示） | `++(1868)年、(明治)維新が起きた` |
| 長文 | `+++`：空欄ごとに1問（他の空欄も隠す） | `+++(1868)年、(明治)維新が起きた` |
| 改行 | `^` | `1行目^2行目-答え` |
| セクション | 行頭に `［名前］` | `［第1章］` |

問題文に `-` を含めたいときは `\-` と書きます（例：`well\-known-有名な`）。

## データの保存について

- 入力した問題・正誤の記録・ピン・設定は、使っているブラウザの中（localStorage）に保存されます。サーバーには送られません。
- 端末やブラウザごとに別々のデータになります。別の端末へ移すときは「名前をつけて保存」でダウンロードした `.json` ファイルを「ファイルを読み込む」で開いてください（正誤の記録も一緒に移ります）。
- ブラウザの履歴・サイトデータを消去すると保存内容も消えるので、大事な問題はファイルにも保存しておくと安心です。

## ショートカット（PC）

- `Enter`：答え合わせ／次の問題へ
- `1`〜`9`：選択問題の選択肢を選ぶ
- `O` / `X`：自己採点で正解／不正解
